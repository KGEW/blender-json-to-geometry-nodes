# 代理模型表面投射顶点均匀化

JSON：`examples/proxy_surface_vertex_relax.json`

该节点组用于已经手工重拓扑的四边面代理模型，不修改工业模型。它保持代理拓扑不变，使相邻顶点距离趋向均匀，并尽量把结果约束在输入代理模型的原始表面上。

## 中文接口

- `几何体`：重拓扑代理模型；
- `均匀化遮罩`：0..1，可使用顶点组或命名属性；
- `松弛强度`：原位置与邻域平均位置的混合比例，内部限制到 0..1；
- `迭代次数`：Blur Attribute 对 Position 的邻域迭代次数；
- 输出 `几何体`。

## 原理

1. Blur Attribute 对 Position 执行邻域松弛；
2. 使用“均匀化遮罩 × 松弛强度”混合原位置与松弛位置；
3. 将候选位置作为 Sample Position；
4. 在输入代理模型原始 Geometry 上执行 Sample Nearest Surface，并采样原表面的 Position；
5. Set Position 把顶点写回原表面位置。

因此最终顶点位于原始离散网格表面上，顶点数、面数和连接关系不变。真实 Blender 5.2.1 的不规则 5×5 四边形平面回归中，边长变异系数从 0.3051 降至 0.0976，平面偏差为 0，固定边界没有移动。

## 推荐设置

- 初次使用：松弛强度 0.2～0.5，迭代次数 1～3；
- 将开放边界、必须保持位置的合模线、硬特征和定位点加入固定区域，即让这些位置的“均匀化遮罩”为 0；
- 多次查看线框和曲率反射，不要直接使用很高强度和大量迭代；
- 建议顺序：代理顶点均匀化 → 代理法向平滑 → 代理锐边距离蒙版 → 向工业模型传递法线/蒙版。

## 限制

这是固定拓扑上的近似拉普拉斯松弛与最近表面投射，不是重新拓扑，也不是严格的等边/等面积求解。它不会执行边拆分、边塌陷或边翻转，所以极端细长面无法保证完全均匀。凹槽、薄壳、自相邻表面或高强度松弛可能让最近表面投射跳到错误位置；连接关系也可能在表面上产生扭曲甚至翻面。应使用遮罩固定边界和关键特征，并采用较小参数逐步处理。
