# 锐边测地距离扩散蒙版

JSON：`examples/sharp_edge_geodesic_mask.json`

## 为什么不使用“曲线转均匀点 + 几何接近”

离散点接近距离会受点间距影响：采样不足时蒙版沿锐边产生波纹；即使重采样均匀，结果仍是到离散点的三维欧氏距离，在折叠表面或相邻壳体之间可能穿过空间抄近路。

本节点组把“锐边顶点组”阈值化为种子顶点，使用 Shortest Edge Paths，并以每条真实边长作为 Edge Cost。得到的是沿网格边传播的近似表面测地距离，不依赖曲线采样点间距。距离经 Smootherstep 映射为 1→0 蒙版。

## 中文接口

- `几何体`：原始模型；
- `锐边顶点组`：锐边沿线顶点权重；
- `锐边阈值`：大于该值的顶点成为扩散起点；
- `扩散距离`：模型空间中的衰减半径；
- `蒙版属性名称`：默认 `sharp_edge_distance_mask`；
- 输出 `几何体` 和 `蒙版`。

节点组同时把结果存到 POINT 域命名属性，便于后续节点和材质读取。

## 限制

Shortest Edge Paths 沿现有网格边计算，所以不会受离散曲线点距影响，但仍会受拓扑方向和密度影响。三角形极度细长、边方向高度单一或局部网格非常稀疏时，等距线可能带有网格方向性；它是离散测地距离近似，不是连续曲面的精确热测地线。顶点组应覆盖整条锐边上的顶点，否则扩散起点会出现缺口。
