# 两种锐边均匀扩散蒙版测试方案

本次只提供两个 Geometry Nodes JSON，不修改插件。

## 方案二：连续边欧氏距离

JSON：`examples/sharp_edge_continuous_edge_mask.json`

中文接口：`几何体`、`锐边顶点组`、`锐边阈值`、`扩散距离`、`蒙版属性名称`；输出 `几何体` 和 `蒙版`。默认属性名是 `sharp_edge_continuous_mask`。

节点组通过 Mesh Edge Vertices 和两个 Evaluate at Index 读取边两端的顶点组权重，只保留两个端点都超过阈值的边。Geometry Proximity 的 Target Element 设置为 Edges，直接计算到连续线段的三维距离，不需要曲线转点，因此不受曲线采样间距或表面顶点密度影响。距离经 Smootherstep 转换为 1→0 蒙版并存入 POINT 域。

优点是快、平滑、参数少；缺点是欧氏距离可能跨过薄壳、折叠或邻近表面。适合平缓耳机外壳和较小扩散半径。

## 方案三：高密度分析代理测地距离

JSON：`examples/sharp_edge_dense_proxy_geodesic_mask.json`

中文接口：

- `几何体`；
- `锐边顶点组`、`锐边阈值`；
- `分析代理细分层级`；
- `代理松弛遮罩`、`代理松弛强度`、`代理松弛迭代次数`；
- `锐边种子捕获距离`；
- `扩散距离`、`蒙版属性名称`；
- 输出 `几何体` 和 `蒙版`。

默认属性名是 `sharp_edge_dense_geodesic_mask`。

节点组内部执行：

1. 提取原代理模型上两个端点都被标记的连续锐边；
2. Subdivide Mesh 建立高密度分析网格；
3. Triangulate 增加可传播的边方向；
4. 对分析网格 Position 松弛，并 Sample Nearest Surface 投射回输入代理模型表面；
5. 用连续锐边距离捕获分析网格上的种子顶点；
6. 以分析网格真实边长作为 Shortest Edge Paths 的 Edge Cost；
7. 把测地距离转换成蒙版；
8. 将分析蒙版采样回输入代理模型；
9. 只在原代理模型上存储 POINT 域属性，内部高密度分析拓扑不会输出。

方案三沿表面传播，不容易跨越薄壳，但仍是离散边图的测地近似。细分越高越平滑，也越耗内存和计算时间。`锐边种子捕获距离`应略大于分析代理的局部点距；太小会漏掉种子，太大会让初始锐边带变宽。

## 建议测试顺序

方案二初始设置：锐边阈值 0.5，扩散距离使用目标合模线宽度。

方案三初始设置：细分层级 1～2，松弛强度 0.15～0.35，松弛迭代 1～2；种子捕获距离约为细分后平均边长的 0.5～1.0 倍。开放边界和关键特征应通过 `代理松弛遮罩=0` 固定。

真实 Blender 5.2.1 回归在不均匀 5×5 四边面网格上确认两组均保持原输出 25 个顶点和 16 个面；中心锐边蒙版接近 1，远侧顶点接近 0。方案二导入后共有 14 个节点、22 条连线；方案三共有 30 个节点、51 条连线，均低于项目协议限制。
